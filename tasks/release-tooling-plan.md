# 发版工具与签名备份计划（2026-11-27）

目标：沿用 0.1.16 的安装身份 / 证书，核对现有密钥并在 Git 目录外建立受 Windows ACL 限制的本机备份，使用备份实际签名临时 APK 验证可用性。增加本地 prepare / verify 发版脚本，串联静态检查、完整主机测试、validation 双 ABI 构建、证书 / 版本 / SDK / 对齐检查、校验文件和更新清单生成。

边界：不改应用版本、包名、证书或功能；不连接手机，不发布新版本，不改变当前公开清单，不复制密钥到仓库。当前版本只以 rehearsal 模式演练，产物明确不可据此当作待发布新版；正常准备必须高于远端正式 / beta 的全部版本且源码已提交。密钥本机备份不是离线 / 异地备份。

步骤：
1. 对照实际构建和当前公开 APK，固定公开证书指纹；记录默认 debug 签名来源，防止环境自动生成新密钥后误发。

3. 备份原 keystore，不改变原文件；验证文件哈希及使用备份签名后的证书。恢复验证只使用明确的新建临时目录，不安装。
4. 执行一次当前 0.1.16 的完整本地演练与候选包 verify，读回记录；本轮不联网发布。
5. 更新发行流程 / HANDOFF / todo；提交推送私有源码仓库，确认无密钥或备份入 Git、公开仓库和手机状态未改变。
