## 实现与自动回归

- 跨城默认 Ask：确认才切换，取消保持原城市；同一 ViewModel 使用期间不重复询问已取消城市，地点变为其他城市后可再次询问。
- “我的 → 出行 → 跨城切换”提供询问（默认）/ 自动 / 保持当前城市；DataStore、旧 SharedPreferences、旧存储迁移和 commonMain 仓库均保存同一偏好，未知值回退 Ask。
- 首次安装无已存城市时自动选定位城市；手动选城及城市选择器“重新定位”仍直接执行。定位结果晚到不覆盖手动选择，旧城市的迟到刷新不覆盖新城站点。
- 启动、显式刷新及成功定位超过 60 秒后恢复首页会检查位置；没有新增后台定位轮询。已有权限 / 系统定位失败重试规则保留。跨城弹窗仅在首页 lifecycle 为 RESUMED 时显示；隐藏页不弹窗，也不把切页当取消。
- 返回顶部在首个可见列表项索引至少 3，或单项滚过视口高度时出现；标准版位于乘车码上方，关闭乘车码后仍可独立使用，长辈版保留至少 64dp 触控尺寸。
- 回顶只滚动并复位标题栏，同时恢复底部“公交 / 我的”；不发送 Refresh / RetryLocation，不改变城市或提醒。保留原有底栏动画。
- Android“我的 → 收藏备份”使用系统文件选择器导出 / 导入 JSON，保留线路、站点、路线、分组颜色和顺序；合并去重、已有项优先，新项追加，冲突编号重新映射。同名分组逐一匹配，不把多个同名分组合为一个。
- 备份格式 `rtbus-favorites` / version 1，上限 8 MB / 10,000 条；检查版本、格式和索引引用，有界读取并支持 BOM。互斥内一次完整写入，成功后再发布状态；不含设置、提醒、定位记录或密钥，不申请存储目录权限。iOS 暂不显示文件入口。
- 首页长按三类收藏均弹确认；取消或关闭弹窗不删除，普通点按仍进入详情。确认按完整类型 key 查找，再调用对应删除接口；同名 / 同 ID 的其他类型收藏保留，过期或未知 key 忽略，不删分组。标准版和长辈版共用确认流程。
- 自动回归先复现旧版失败，再完成设置与回顶 UI、手动选城竞态、存储重开 / 迁移、备份合并去重 / 同名组 / 并发 / 写失败，以及三类同 ID 精确删除、取消和根导航测试。Robolectric 渲染与真机截图已检查，无本轮弹窗文字裁切或按钮重叠。

## Android 真机验证

设备为用户已连接的 Xiaomi 22041216C；最终包使用既有包名与证书覆盖安装。以下是本轮操作的功能验证，不代表所有设备或帧率测试。

- 跨城询问：手动选择其他城市后，用手机真实定位触发差异；取消保留且刷新不重复提示，确认切到定位城市。保持当前城市模式重启后仍保存；自动模式刷新后回到实际定位城市，最后恢复 Ask。这是定位差异流程测试，没有物理跨城旅行或修改模拟位置。
- 回顶：滑动使底栏收起，再点返回顶部，列表回顶且底栏恢复；“我的 / 公交”可立即操作。关闭乘车码和长辈版的回顶也已验证，测试后恢复乘车码开启、标准版。
- 收藏备份：由 App 真正导出 JSON，经系统选择器导入恢复已删除的测试收藏；再次导入提示导入 0 条、跳过 1 条重复。导入 / 导出选择器取消后仍可操作；不支持版本的文件被拒绝，原收藏及分组保留。
- 标准版长按：线路收藏弹窗显示具体条目，取消保留、普通点按进入详情。为线路 / 站点 / 路线构造相同底层 ID，依次确认删除站点、路线、线路，每步均保留其他类型，最后测试收藏为空且原分组保留。
- 长辈版长按：从真实导出文件恢复测试线路，长按取消后保留，再长按确认后收藏区显示空态；附近列表中的同线路仍正常显示。
- 持久化和清理：确认无追踪服务后重启 App，测试收藏没有恢复。最终再次由 App 导出，`stops` / `stations` / `routes` / `items` 均为空；原两个分组完整对象（编号、名称、颜色、顺序、默认属性）与测试前导出逐项一致。没有删除用户分组。
- 最终状态：广州、跨城询问、乘车码开启、长辈版关闭，停留公交首页。仅删除本轮创建的四个 Download 测试文件，卸载临时 probe 工具，保留 RTBus 和用户数据，关闭 ADB 服务。
- UI 快照、截图、原始备份与机器验收摘要仅保存在忽略目录 `build/rtbus-validation/city-scroll/phone/`，不进入源码或远端；摘要为 `final-acceptance-summary.json`。
