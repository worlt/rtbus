# 跨城确认与返回顶部验收（2026-11-27）

## 实现

- 跨城默认 Ask：确认才切换，取消保持原城市；同一 ViewModel 使用期间不重复询问已取消城市，地点变为其他城市后可再次询问。
- “我的 → 出行 → 跨城切换”提供询问（默认）/ 自动 / 保持当前城市；DataStore、旧 SharedPreferences、旧存储迁移和 commonMain 仓库均保存同一偏好，未知值回退 Ask。
- 首次安装无已存城市时仍自动选定位城市；手动选城及城市选择器“重新定位”仍直接执行。定位结果晚到不覆盖手动选择；刷新旧城市的迟到结果也不覆盖新城站点。
- 启动、显式刷新及成功定位超过 60 秒后恢复首页会检查位置；没有新增后台定位轮询。已有权限 / 系统定位失败重试规则保留。
- 跨城弹窗仅在首页 lifecycle 为 RESUMED 时显示，隐藏页不弹窗，也不把切页当取消。
- 返回顶部在首个可见列表项索引至少 3，或单项滚过视口高度时出现；标准版位于乘车码上方，保留底栏避让。关闭乘车码后仍可独立使用。长辈版保留至少 64dp 触控尺寸。
- 点击只调用列表滚动与标题栏复位，不发送 Refresh / RetryLocation，不改变城市或提醒。

- 设置入口与返回顶部回归在旧实现上均按预期失败；补充“手动选城时定位尚未返回”竞态测试先失败后修复。原始红灯 XML 仅保留在 build 忽略目录。
